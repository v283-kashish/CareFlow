# CareFlow

CareFlow is a healthcare process mining project developed as part of the Infotact Solutions internship.

## Project Goal

The project analyzes simulated Electronic Health Record (EHR) event logs to discover the actual patient journey and identify operational bottlenecks.

## Technology Stack

- Python
- Google BigQuery
- dbt
- PM4Py
- Power BI / Looker

## Project Pipeline

Python → EHR Event Logs → BigQuery → dbt → PM4Py → Dashboard

## Main Objective

To discover hidden process inefficiencies in the patient journey and present the findings through an interactive dashboard.
